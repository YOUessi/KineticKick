# v121 分析可辨识性更正：预接触窗口左删失（保留初版负证据）

记录日期：2026-11-12。原协议冻结提交：`d90a7ebfb6a4284237eff74e0a5862f7412c868b`。本更正发生在首次阅读跨版本历史数据的初版报告以后，因此是**公开的事后证据解释修正，而不是宣称原来已经预注册了这条规则**；没有调整0.4s、20%峰值、0.5W、3个连续真实采样等数值，也没有训练任何政策。

初版审计 `reports/v121_frozen_crossversion_29dof.audit.json` 将触球前-0.4秒的首次可见高功率等同于“真实动作起点”。该算法在24/24独立真实G1原始物理轨迹上输出腰→髋→膝→踝的观察顺序。独立检查发现，腰、右髋、右膝在该窗口第一帧就已活动，真正起始时刻在观测窗之前，无法根据窗口内第一帧赋予物理发生顺序。此时“支撑在髋启动前没有三连续帧”也不能判否；其真值未知。

更正后的结果另写 `reports/v121_leftcensor_corrected_29dof.audit.json`（写一次），对首次高功率恰在窗口左边界的组赋予`onset_left_censored_by_pre400_boundary=true`。只要排序必要组中有一个左删失，就令`identifiable_waist_hip_knee_ankle_order=null`；若右髋左删失，则“髋发力前支持已建立”也为`null`。保留`naive_window_waist_hip_knee_ankle_order_NOT_CERTIFIED`供追溯。16组CMU-v32配对的起点差值对含左删失的组同样为`null`。

更正后 **24/24的完整动力链启动顺序均不可辨识**；不能把初版24/24当成完整人体式动力链通过。不同组的触球前400ms估算机器人电机功和时间质心仍可作描述，但无法从其顺序直接推出人体式力传递。恢复识别需要扩展到真实助跑开始前的完整高频动力学和支持/接触观测，而非调阈值“优化结果”。
