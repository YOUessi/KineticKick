# v0.1.7 连续助跑射门设计

用户已确认：助跑→调整支撑脚→小腿主导或大腿主导击球→随摆→恢复平衡，并要求真实仿真预览。延续三种触球面/定点力度目标；新能力未验收前不替换 v0.1.3 稳定入口。

在当前29DoF PAiD本体、原始碰撞/执行器限幅上扩展参考与观测控制。优先验证已有较长原生参考006/009/010（有历史物理成功证据），保留同一物理机器人、同一球与循环策略状态。37DoF步态策略的动力学不兼容，不作为无需验证的拼接来源。

全过程禁止固定根、仿真开始后写机器人/球状态、重置或外力推球。仅修改目标参考、正常关节执行器输入；末尾参考保持不循环重置。模式表示接触前足端运动的髋/膝贡献，不能由名称或关节角外观认定，也不能声称等于机械做功。

增加每5ms同步记录：关节速度、执行器估计扭矩（明确implicit PD估计性质）、速度/扭矩限幅、各脚地面接触力、全身质心、足端速度的髋/膝/踝/根贡献、失败原因。检查真实接触、球门穿越、助跑位移/速度和连续稳定恢复。

完成证据：两种模式实际可区分，短程助跑≥0.7m且峰速≥0.5m/s；有效触球进球；最终连续稳定≥1s；全程无跌倒或明显非脚支撑。助跑不等于双脚腾空奔跑，另外报告腾空证据。先以原生参考验证，再有依据地修改髋膝参考时序；不能无限盲扫。

执行界限：首轮3个原生候选，每轮至多12回合；同类失败两轮后必须根据遥测换诊断/路径。单次GPU进程限于一批短rollout，不启动无界训练。验证通过的候选再做球位扰动/新种子矩阵和完整预览；失败也保留完整录像并明确未完成，绝不拼接成成功。
