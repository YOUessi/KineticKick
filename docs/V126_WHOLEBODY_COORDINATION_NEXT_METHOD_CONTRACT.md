# KineticKick v0.1.126 — KineticChain-29 下一阶段的可证伪生成控制研究合同

状态：**尚未训练、尚未实际电机驱动、尚未通过原生碰撞安全认证**。本文件不是一项已实现的专业抽射能力。

## 1. 本批决定：现有 CMU 弱参考不能作为主方法

原 v32 和两个 CMU 弱参考在八个预见过的物理场景下，严格成功 4/8、5/8、4/8。受控成对精确检验的双侧 p 均为 1.0。CMU02 只有两个场景由失败变成功，另有一个场景由成功变失败。旧参考首次改变实测原 G1 轨迹于 1.405s、距触球不足 0.18s；没有从原始静止启动的助跑学习证据。不能把球位适应性、临近触球的 1mrad 小参考、离线关节角 MSE、单纯进球当成自然全身运动的主贡献。

## 2. KineticChain-29 的待实现核心设计（不是参数微调）

**条件输入**：经过真实人体数据资格认证的连续 pelvis/shoulder/arm/leg 三维骨骼时序、缺失信号掩码、被试ID、合法脚球接触时间标签、球/球门几何，以及实时原 G1 29DoF 的 q、qdot、基座、支撑足、COM/角动量和安全接触状态。职业球员身份、同步GRF、CoP、脚球冲量缺失时，不计算相应损失，也不称为「已学习专业发力真值」。

**共享动作表示**：整个动作只使用一个连续全身运动隐变量序列 z(t)，不是分别独立生成落脚/摆臂。七段单调但可变长的相位：静止/缓起步与 approach、support establishment、backswing、pelvis+trunk acceleration、instep impact、follow-through、landing/recovery。每个阶段输出经原始关节顺序映射的 29DoF q*、dq* 和期望全身质心/角动量动力学目标，并延伸到触球后完整14秒。运动相位由可观测支撑/接触事件标注，不再信任旧日志 coordination_phase=idle。

**可执行的控制优化问题**：接上 v117_witnessed_horizon_admission 和 v107_motor_admission 的全部29DoF门禁；用阶段连续的全身轨迹作为参考，优化在 PhysX 中可实现的接触约束、质心支持、躯干/骨盆动量分配、右腿摆动和左/右摆臂互补、落地稳定，而非仅最小化足端误差。未来在线控制器必须做逐步 q、qdot、qddot、扭矩、支撑/摩擦、足底滑动、真实碰撞距离和机械自碰撞约束；native collider/actor/point/normal/impulse 或来源不明时不能用未知=安全代替。

**目标函数主研究维度**：真实人体全身相位同步与互补、动态平衡和自然协调生成；射球的正脚背合法冲量≥95%、真实球速代理≥3.5m/s、球门几何、全部原29 qdot、非脚危险力<20N、14秒落地稳定是不可权衡的硬门禁。速度和自然性都不能通过放松 qdot 或隐藏非脚碰撞获得。

## 3. 下一次可以批准 GPU 实验的证据依赖

A. 原生接触正控制必须在现有 Isaac Sim 4.5 运行时真实发生，至少记录 actor0/1、collider0/1、point、normal、impulse，采用同时读回和回调原始缓存读取的两条路径，绑定真实 USD SdfPath 和刚体所有权；再验证分离负控制。离线 URDF 静态几何不具备此资格。

B. 原 G1 3 回合 OFF/ON 必须在未改控制器、未改滤波器/接触参数的条件下逐值相同；如果开启接触报告需要在 USD 上写 Schema，这只是观察器条件的一部分，不能预设一定对物理无扰动。观察器改变物理时整批无效。

C. 新人体数据必须经独立被试/试次资格审核，至少形成三个不重叠非空的 train/val/test，被试与专业射门证据须实标，不能将 2 名被试人工拆分为多个独立人。若只有普通运动学，不允许训练「人体专业力学监督」；可以验证工程 pipeline 但必须在论文中标明局限。

D. 在学习/优化之前冻结新球位、随机种子、独立负例、协议SHA、训练与未见测试分界。AG–AN 不再算盲测。对照组必须包括原 v32、旧 CMU、机器人-only phase、人体真实时序、人体时序打乱、锁摆臂、锁骨盆、去支撑约束、完整29DoF。由同等物理采样量和测试条件评价。

E. 除硬门禁，还要有时间可识别性：静止初帧真实 qdot 和根部速度、小跑助力、双足支持载荷重心转移、骨盆相对肩带相位、摆臂对角动量、触球到落地动力学。当前早期机器人轨迹已经在1.8m/s速度开始，不允许把其0.02s功率阈值称作自然从静止起跑。

## 4. 可复现实验的科学假设

H1：在同一冻结球位/种子集合上，合格真实人体全身时序输入和支撑-自碰撞安全控制可以提高跨部位时序自然性、恢复稳定性和严格成功率，且不以 qdot 与非脚碰撞安全下降为代价。

H0：全部所谓进步可以被机器人-only 相位和更好的球位规划解释；不存在可证明的专业人体时序贡献。任何无独立被试、无 native collider真值、在已看失败案例调参而只报告成功案例的实验，不得支持 H1。

本版的静态 URDF 候选发现与小样本精确检验结果只能改进下一轮研究决策，**不能**证明 H1，也未发布任何可下发到电机的学习模型。
