# v132 原始G1全身碰撞几何范围审计 — 先冻结

独立基线：已验收 v130 SHA `7f3c0e7880ba68743787d29224c1ea679ef70e04`。由于v131独立分支已有未提交在研文件，本版本在独立工作树从已完成的v130分叉，不修改v131。

研究问题：之前v127–129集中于左腕和左髋。原URDF共有28个圆柱及1个球碰撞形状，系统性地检查其余非相邻身体部位是否也在原v54真实物理事件前接近，从而发现既有窄配对分析的盲点。

**冻结设计**：只读取SHA认证的原v52/v54三组原始200Hz轨迹，分别2800/2800/1028真实状态，明确排除5.140001秒的非物理终止重复。按原始29DoF排序重建前向运动学。所有形状用外包胶囊（圆柱半长轴端点+半径、球为零长度胶囊）形成保守空间间距下界。只对原始URDF树路径距离≥3条joint边的不同links计数；被排除的近邻配对为**未评估**而非安全。每组实际输出符合条件的配对总量、窗口内前十风险对、全时最小几何下界、预冻结20/50mm预警以及5.135s的相邻部位排位。用固定5.080–5.140秒观察窗口，绝不把5.145秒传感器事件补插成真实关节姿态。

**可证伪性**：若除左腕—左髋还有其他非相邻链接出现≤20mm外包胶囊下界，本轮明确报告候选，不能归因唯一腕髋；若全部正下界，可排除对应**原URDF离散时刻**的这些形状重叠，但不能据此证明真实USD运行时无接触。下界≤0只表示外包形状可能重叠，永远不是实际接触认证。

**负控制**：原始SHA/时间/关节排序篡改必须拒绝；同一link、拓扑上相邻的link不得冒充有效候选；合成几何相交不得被提升为PhysX真值；缺少5.145s真实状态必须维持UNKNOWN。对有限圆柱与球分别做独立三维几何参考检查。
