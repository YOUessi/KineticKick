## C — New KineticMimic contact-conditioned **causal whole-body observer** (NOT actor)
All training labels arise solely from recorded robot PhysX; never claim professional human biomechanics or actual transferred motor skill. From physically verified historic v84 C/D original robot episodes, learn the 20-frame (100ms) ahead full29DoF joint velocity and support state conditioned on *current* stance and time since support transition, body COM, root-ball geometry, current pose and velocity; NO true time-to-future-impact, impulse or labels as input. Metrics: 29DoF normalized velocity MAE/p95 and support-state transition accuracy/macro F1; full-contact windows (touch ±0.4s,+1.25s), physical gate failure and structural timing proxies remain separate.
