# KineticKick｜下一批研发任务清单（不按日期，按证据验收）

> 此清单是 [当前总目标与计划](RESEARCH_OBJECTIVE_AND_ROADMAP.md) 在开始执行时应遵循的**最小成组任务队列**。实验需要实际执行，不得把这份待办清单本身作为完成证据。历史批次仍留在 [旧研究计划](RESEARCH_BATCH_SERIES_2026-11-11.md)。

## W0：设备、物理证据与原G1运行时闭环

- [ ] **W0.1：进程与资源只读审计。** 核实Tang旧v120 `pytest` PID、父子进程、GPU上下文/堆栈、原日志与启动时间；记录是否仍在有效计算。未完成取证前不能抢GPU、删除进程或覆盖原日志。可用磁盘不足20GiB则不得创建大PhysX输出。
  - **交付：** 源SHA、作业pid与日志、GPU与空间、下一步安全决议；CPU-only旁路工作可继续。
- [ ] **W0.2：真实同物理步数据契约。** 为原自由根G1补采实际root quaternion、6D root velocity、29q/dq、双足contact patch、原生刚体双方及脚球/非脚碰撞事件字段，区分原URDF/Pin模型值与PhysX运行时实际测量。
  - **验收：** 读取器拒绝缺root6D、伪补0、错关节顺序、1µs终止哨兵、跨时钟拼接。
- [ ] **W0.3：原生contact正负校准。** G1鞋底/脚球已知阳性、分离刚体阴性、旧v54 left wrist/hip强候选；native contact observer须具有真实两侧actor/collider/形状/点/法向/时间，并进行OFF/ON同一场景全5ms状态对等认证。
  - **验收：** 原生contact得到可信阳/阴及非干扰性；否则明确卡在本模块，不能让未验证新Actor直接进入物理。

## W1：全身Mimic小脑基线（与W2数据收集可并行）

- [ ] **W1.1：PAiD13段原G1运动库资格清单。** 验证13份50Hz `.npz` 的G1 29DoF真实顺序、root/body poses、长度、SHA、许可与实际源场景；质量报告明确哪些是已重定向视频、哪些是踢球/跑步，不能把轨迹文件当真实小脑执行。
- [ ] **W1.2：标准全身Motion Tracking复现。** 先复用已有G1仿真环境与原PAiD训练资源；必要时对比SuperMimic/HoloMotion开源接口，冻结SHA与环境。小脑输入参考、当前实测全身状态和真实足地接触反馈，输出完整29关节，实时闭环至少执行一段连续动作。
- [ ] **W1.3：跨动作与安全回放。** 选择不同root运动、踢腿/支撑/双臂动作，记录真实 q/dq/foot-slip/root/ball/非脚碰撞/恢复以及是否错误地只靠球位硬编码。
  - **验收：** 至少一条新的**小脑跟踪**PhysX完整动作有源证据和全套失败审核；尚无原生碰撞资格时输出明确 `NOT_CERTIFIED`，不谎称安全。

## W2：真人足球动作数据与G1重定向

- [ ] **W2.1：专业正脚背完整动作来源筛选。** 对已有CMU/3DSP/视频素材以及经授权的新来源创建数据资格表：球员/片段/帧率/许可、是否完整助跑—随挥、脚球真值/足底GRF/球轨迹真实与代理区分。
  - **验收：** 多被试训练/测试集合不存在同人泄漏；现实数据不足则把论文高水平/功率真值声明保持未满足，不得用模型生成假标签填补。
- [ ] **W2.2：人体段落到原G1任务空间映射。** 先做pelvis/trunk/两臂/双腿/左右脚/接触阶段的时间对齐、脚部可达性、足滑/脚背方向与URDF限制检查，再生成全长29DoF参考；必须保留真实 source confidence/missing mask。
  - **验收：** 至少一条可信人体动作**完整序列**→可追踪G1参考；不是仅触球前17帧微小残差，参考离线通过不替代真实物理。

## W3：行为隐空间与接触条件化首轮可消融训练

- [ ] **W3.1：CVAE /无latent对照。** 以训练人/动作生成 `z`，输出全身G1参考；只用训练/验证超参选择，独立测试报告动作重建、跨动作/跨人泛化、模式多样性、连续时域关节和空间合法性。
- [ ] **W3.2：Contact-conditioned Skill。** 输入实时支撑、球位与射门目标，不直接依赖绝对撞击时钟；冻结无contact、无latent、时间反转、仅右脚/冻结双臂和「训练集撞击时间中位数」强负控制。
- [ ] **W3.3：小脑对接与物理安全门禁。** 有完整原native collider证书才能允许新策略受控驱动G1；每次原全29DoF动作非零/真正物理响应、足端球速/冲量/方向、非脚接触、14s恢复逐条件验收。
  - **验收：** 首次真实29DoF新动作闭环，要明确记录新模型每5ms实际控制是否生效；若失败保留为失败分母，不能用旧v32的进球替代。

## W4：论文对照、自然度与可发布成果

- [ ] 与原v32、标准Mimic、AMP、latent无contact和完整方法，在相同资产/预算/真正独立球位种子上比较，冻结至少一组完全未用于模型选择的测试。
- [ ] 对**严格物理合格**的生成动作做配对盲评（自然/连贯/运动美感），报告评审间一致性、统计不确定性、失败动作和示例视频来源；全部关节与足球记录可回溯。
- [ ] 输出论文图：真实足地接触序列、骨盆—躯干—腿—双臂相位、foot-ball真实冲量与足球速度、latent插值多样性、强消融曲线、完整通过率及right-censored终止。
- [ ] 最终只在上述条件满足时宣称**新的接触条件化全身技能方法成立**；否则保留清晰可复现的负结果并调整算法假设。

## 每个大批次必须一次交付的内容

```text
source/asset/runtime SHA preflight
  -> 冻结人/球位/动作/种子/训练预算和失败停止规则
  -> 实现方法 + 专项测试
  -> 实际训练（若允许）与多个真实配对PhysX（若GPU和证书允许）
  -> 物理原数据独立审计（不补造缺失帧）
  -> 新方法 vs 旧baseline vs null/ablation
  -> 整批报告 / 失败归因 / 真实回归测试
  -> GitHub独立版本分支commit、push和远端SHA比对
```

**任务优先级顺序：** W0必要的接触/原生数据资格 **与** W1小脑低风险复现 **与** W2真人数据可以并行；W3需有可用的W1和W2后才可以声称人类式生成；W4需要真实W3物理执行。无GPU时，实质性完成W2/W3的CPU数据和预注册负控制，不能拿CPU测试计作G1新射门。

**不可删改的事实边界：** 本清单本身没有跑新的PhysX、没有训练新latent、没有安装SuperMimic或BFM；任何执行结果只由对应未来提交/原始物理证据确认。
