## Post-acquisition interpretation amendment (no new simulation)

The single replay completed with 2800 original physical rows unchanged. The collector marked four right-foot bins invalid because it assumed the raw scalar returned by `get_contact_data` must be nonnegative. Preserved raw arrays contain signed coefficients. The installed SDK example aggregates `coefficient * raw_normal` directly; it does not establish a nonnegative magnitude contract. Without absolute values, normal reversal or sign fitting, the four reconstructions agree with their force matrices within 3.43e-5 N and the opposite foot-side matrices sum to zero. Buffer ranges/capacities and active values remain valid. The original collector, report and strict audit rejection are retained.

A separate, explicitly selected offline signed-raw interpretation is authorized on these same saved arrays. It must reconstruct every pair, preserve the coefficient and normal signs, recheck capacity/finite values and opposite actor matrices, and then apply the original fixed 0.02 N s momentum criteria. It cannot silently turn the original acquisition flag into success or count a second physical trial. The first strict analyzer also flagged a relative-versus-absolute probe path; only aliases resolving to the same actual file with the same verified hash may be treated as equivalent acquisition metadata. All original control and physical fields remain exact. Signed-data arithmetic does not prove a universal SDK scalar convention or a solver mechanism.
