# New full-body kick source audit — 2026-11-07

**Result: no qualified new public raw-motion source found in this bounded round.** Three previously unaudited leads were checked against official publication/repository metadata. None supplies directly downloadable, licensed original whole-body time series for skilled/elite maximal instep kicks. This is a scoped search result, not proof that no such dataset exists. P2 remains unmet; unknown accuracy has not been relabelled as measured poor accuracy.

Scope: up to 15 minutes and three new candidates; started 00:06:33 UTC and closed at 00:10:33 UTC (4 minutes). Existing source notes were read first. CMU, SkillCorner, KTH, MUVY, WorldPose/SportsPose access gates, Wilmes 2020, Vieira 2022/OSF jer9u, Zhou elite/amateur, SoccerKicks, 3DSP, xGHub and the prior EEG/OSF source were not re-audited. Search results returning these sources were discarded. Discovery queries targeted instep/maximal soccer kicks plus raw data, C3D, full-body, Zenodo, Figshare, OSF and university repositories. Broad results were screened by title/snippet; substantive source audits were limited to the three rows below.

Only public pages/metadata and article text were read. No raw dataset or video was downloaded locally, no file over 10 MB was requested for local acquisition, no author was contacted, no access request was submitted, and no dependency/GPU/training operation occurred. This note records the independent read-only audit.

Article access is distinct from data access. The two explicit publication licenses above cover the displayed published work; they do not create a downloadable raw-motion release or permission to infer one. None of the three has an exact public raw-data URL with a verifiable file list and reuse basis in the checked records.

**Inspection limits.** The Chichester record and indexed primary article text were readable; direct publisher/PDF fetches encountered 403/timeout, so no unsupported claim is made about an unlisted private archive. The Applied Sciences page returned 429 on direct open; the search tool returned indexed text from that same official page, including the explicit raw-video/conditional-data restriction. Its full supplementary file manifest and sizes remain unverified. The CISS full HTML and official landing page were readable, including the request-only data statement; no request was made. A DataCite API discovery URL was not accessible through the browsing tool and was not treated as a complete registry search. These retrieval limitations are recorded rather than interpreted as dataset-quality failures.

The three-source limit has been reached; this round is **closed**. The valuable unresolved route is an explicit public release containing original, unnormalized full-body trajectories (or original synchronized/calibrated views), participant skill evidence, instep/maximal-effort protocol, and trial metadata. This round found no such immediately actionable release. It therefore does not justify a new download, an author-application workflow, or further same-source probing. Existing public-data engineering may continue under its current qualification limits, but cannot be presented as the requested high-level human instep evidence.
