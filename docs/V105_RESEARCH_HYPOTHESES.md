# KineticKick 研究假设更新：全身自然协调并非同时变化

- **H1（待检验）** 合格优秀真人正脚背抽射应表现出可区分的助跑、支撑脚建立、骨盆/躯干动量传递、踢腿加速、对侧摆臂、随挥及双足稳定期。不能以所有身体组在一个控制时刻同步偏移当作“学到真实发力链”。
- **H2（历史数据反例）** v97/v98里原v32对CMU02/05的10个原G1 PhysX控制配对，不论关节角/速度阈值从1e-7变到1e-3，所有身体组差异均同时开始于1.405s。阈值1e-2仅延至1.410s。说明旧参照具有全身共同触发，而非自然时序因果链的认证。
- **H3（安全约束）** 触球是否命中、球速是否超过3.5m/s只能算最低门禁；还必须全原29关节q/qdot/qdd/力矩、正脚背冲量≥95%、支撑地面反力及CoP、原生自碰撞路径/冲量、真正随挥落地和14s站立；任何一项失败不得由进球冲抵。
- **H4（人类数据资格）** CMU同一被试120Hz非射门真实接触时刻相位代理不能充当职业运动员正脚背射门与同步GRF真值。所有实际学习声明必须明确真人数据来源、许可、职业资格证据、同步力数据与标签可信度。
- **H5（仿真取证）** v105单次严格执行了G1环境内可观察650个20ms控制step日志，却被解释器级追踪减速和75s watchdog截断，未留原始完整200Hz JSON；其最重要结论是“不再能简单把症状说成初始化前挂死”，而非“已恢复可认证射门”。

**下一实验预注册要点：** 不带全局trace的单场景完整原始物理正控制；同seed OFF/ON做不可被修改的每字段相等审计；获取真实原生collider双方路径之前拒绝新生成器电机控制；提前终止一律右删失。独立训练/验证/盲测球位、随机种子、人体动作都必须先分组冻结。
