> **项目当前唯一的前瞻性研究目标与计划入口。** 本文件取代旧的 [2026-11-11 连续批次计划](RESEARCH_BATCH_SERIES_2026-11-11.md) 作为未来研发方向的依据；旧文档、既有代码及实验结果保留，绝不重写历史。
> **起点：** 已审计的 `version/v0.1.158` / `fcb8d53560e81c69a47671655b89f8a0368eb068`。本文件为**研发规划**，不表示本文列出的研究模块已经训练成功。

## 0. 一句话科研目标

**让29DoF Unitree G1从优秀真人足球动作中学习全身动态协调规律，能够根据足球位置、支撑状态与射门目标，生成此前未直接示范过的、自然流畅且具有高爆发力的正脚背抽射动作，并在真实物理仿真中完整执行、合法触球、随挥及站稳。**

本项目研究的是**全身技能生成规律**，不是逐帧复刻某位球员，更不是用脚碰到足球就算成功；也不把已有 RoboNaldo 一类“触球式射门”当作期望动作形态。

- **主要科学目标：** 从人类示范中学习可重用的骨盆—躯干—支撑腿—踢腿—双臂协调、接触阶段和动作生成分布，并证明新动作的自然性、协调性、多样性和跨情景泛化。
- **必要功能约束：** 合法正脚背接触、有效足球速度与方向、合理助跑和真实落脚恢复。
- **不可交易的物理/安全约束：** 原G1全部29关节位置/速度/有证据的加速度和力矩限制、真实足地支撑、非脚碰撞、完整14秒恢复。自然性分数或进球不能抵消安全失败。
- **论文落点：** 一种可解释/可消融的 *Contact-Conditioned Whole-Body Behavior Latent* 学习机制，而不是「BFM + AMP + 足球奖励」的简单拼装。论文创新性是待验证假设，不在实验前宣布足够新颖。

## 1. 研究问题（RQs）与可证伪的核心假设

| 研究问题 | 待验证假设 | 必须允许出现的反例 |
|---|---|---|
| RQ1：动作规律 | 相比仅追踪关节角，人类全身相对阶段和时序表示更能跨动作/人/机器人形态泛化 | 无人体条件的模型优于人体条件；相位标签交换不影响结果 |
| RQ2：行为隐空间 | 潜在技能变量 `z` 可在物理有效范围内插值、组合，生成未见过的射门动作，而不只是重放训练片段 | 仅重建训练集、输出模式坍塌、换 `z` 只改少数关节 |
| RQ3：接触条件化 | 真实支撑与首次脚球碰撞事件使动作阶段具有反馈性、比固定时钟控制更稳健 | 训练场景中位触球时间的简单规则优于学习器 |
| RQ4：物理执行 | 可执行全身小脑 + 接触/动量物理优化可将新动作稳定转成合法正脚背冲量 | 仅离线MSE改善，G1执行后超速、非脚碰撞或恢复失败 |
| RQ5：自然性 | 新策略相较标准Mimic/AMP/无隐变量方案产生更自然、更丰富的**合格**完整全身动作 | 自然性盲评不显著、未见球位只剩一种动作或牺牲球速 |

这些都必须通过预注册、独立划分和公平对照检验，而不是依靠漂亮视频或单一脚部轨迹判断。

## 2. 方法路线：大脑、小脑、物理反馈

```text
高质量真人足球动作视频 / 高速 MoCap + 可信相位 / 接触标注
             │
      数据资格与许可审计
             │
   Human Motion / Phase Representation
             │（跨形态语义：pelvis/trunk/arms/stance/swing）
             ▼
   Motion Retargeting → G1 29DoF 全身参考库
             │
             ├────────► Standard Motion Mimic / AMP：独立对照
             │
             ▼
       Behavior Latent Encoder
             │  z = E(human motion, context)
             ▼
       Contact-Conditioned Skill Generator 【拟研究方法】
             │  z_t ~ p(z | robot state, ball, support, goal)
             │  输出：相位/身体协同目标/全身参考，非直接绝对时间模板
             ▼
     Whole-Body Mimic Policy（小脑，先复现可信底座）
             │  G1 29DoF + 真实浮动基、根部状态、接触反馈
             ▼
  Whole-Body Control / Physics-Constrained RL
             │  合法正脚背、全身动力学、非脚碰撞、着地恢复
             ▼
     同一套真实G1 PhysX硬门禁 + 独立自然度评估
```

**研究初版选择：** 以小规模 CVAE/时序 latent policy 为可实现、可强消融的基线；同时比较 BFM-Zero 风格的 Forward–Backward/目标条件化表示。SuperMimic、HoloMotion 是待验证的全身追踪底座或强基线；HumanX/XMimic 和已有足球 Mimic 是论文最直接的相关工作，不假设已接入或复现。必要时再选更强模型，**不预先押注模型越大越好**。

**必须区分：**
1. *Reference Motion*：已有 PAiD/G1 或人体重定向后期望运动，**不是实际物理执行**。
2. *Motion Tracking / Mimic 小脑*：按机器人真实状态执行参考的策略，**不自动生成新动作**。
3. *Behavior Latent Generator*：从条件与学到的表示生成新轨迹/目标，**训练输出不等于能直接控制 G1**。
4. *Contact-aware Physical Controller*：验证原 G1 执行器、浮动基、脚球与足地动力学，**不能用离线URDF/QP代替真实 PhysX**。

技术损失与接口、消融、数值安全边界见 [KineticMimic 方法合同与评测](KINETICMIMIC_METHOD_AND_EVALUATION.md)。

## 3. 按依赖推进的研发模块

### M0：复现基础设施与物理真值认证（全部模块的运行门禁）

**任务：** 固定 G1 29DoF 和实际运行时USD/PhysX资产、原政策与参数SHA；解决/隔离长期挂起的 GPU 进程；校准 native 接触回调的真实 actor/collider/manifold/接触点、法向与时间戳；取得可靠的浮动基姿态、线角速度、全部29关节 `q,dq`、执行器与足地支撑观测。将 Pinocchio 35D 原URDF动力学和运行时动态来源严格区分。

**验收：** 正/负接触对能同时通过；真实脚球、足地和非脚接触对象在同一物理帧可归属；OFF/ON读取不扰动物理；已冻结的真实 G1 可完成 200Hz/14s 正控制；全部原始文件SHA、时间戳、缺测与终止事件明确记录。欠观测时保持 `UNKNOWN / NOT_CERTIFIED`，不能降级成“没有碰撞”。

**安全先决：** 当前v120的长期 `pytest` 曾占用GPU上下文，必须先做进程栈/日志/父子关系及资源审计，不能随意杀掉别的工作、重复占用GPU；磁盘余量不足20GiB暂停新的大物理矩阵。

### M1：基础 G1 全身 Mimic 小脑（可与 M2 数据审计并行）

**输入：** 现有来源清晰的 PAiD 13段G1足球运动、已验证 LAFAN1 29DoF行走/跑步以及之后资格合格的人体重定向参考。

**任务：** 原始参考关节顺序/FK/根姿态/足地事件校验；复现标准全身追踪控制器，确定能在 G1 原动力学下执行步行、跑动、支撑换足、髋部旋转、摆腿、双臂和收势；比较现有 PAiD policy 与可复现的 SuperMimic/HoloMotion 等底座（公平资产、随机种子与动作集合）。

**验收：** 留出完整动作片段中的真实 G1 追踪，记录根姿态/29q,dq/脚滑移/足地接触/碰撞/摔倒、实时动作和恢复；覆盖至少一个连贯的全身动作序列，不以单帧角度MSE或一次“碰球”代替动作执行。未取得M0关键碰撞证书前，允许离线/隔离实验但**不晋升新的危险电机控制器**。

### M2：真人足球数据与动作重定向

**输入：** 已持有的 CMU 120Hz 两被试六段（仅10_02/10_05有连续球标记证据、且同一被试），旧视频估计3D、以及后续有授权的多球员完整射门动作；先评估有无职业/高水平动作依据。

**任务：** 建立 `player_id / session_id / clip_id / source_license / frame_rate / scene / camera / ball / contact_event_source / GRF / CoP / quality_flags` 元数据；区分**实测**与**从视频推断**的接触/足底反力。恢复完整 root/躯干/骨盆/双臂/双腿运动、识别助跑—plant—coil—swing—impact—follow-through—recovery，并优化 G1 可执行全身重定向。视频转3D可当几何风格弱监督，但不能被称为足部冲量真值。

**验收：** 来源/许可/缺失值/接触可信度可审计、按球员隔离的 train/val/test（同一球员不同片段不得冒充跨人测试）、全动作首尾及支撑事件覆盖、原G1 URDF关节与足端运动学合法性；无法获取精确真人GRF时，将 Impact 学习监督限定为机器人仿真实测且显式注明。

### M3：Behavior Latent Skill 基线（首先证明“不是动作记忆器”）

**任务：** 对已合格的全身动作学习编码器/解码器；优先小型 CVAE 和无 latent 的标准时序/追踪模型对照，评估 `z` 的重建、插值、可控组合、跨动作与跨球员泛化。输出可供M1小脑追踪的全身轨迹/任务空间协同目标；比较基本 BFM 风格行为表示，不直接从 `z` 推断力量标签。

**验收：** 新 `z` 能在多个全身关节组和持续相位上产生非平凡、物理可行的差异；生成结果不只在训练集好；评价真值与基线严格同源同预算；至少覆盖支撑腿、双臂、骨盆与踢腿，没有“只动右脚”的退化。只做离线几何则标记 `OFFLINE_ONLY`。

### M4：接触条件化 KineticMimic（论文核心候选）

**任务：** 将可观测的双足支撑事件、球相对几何、动作目标与行为隐变量耦合，按**实际接触状态**推进动作相位，而不是输入绝对固定时钟；加入骨盆—躯干—踢腿—摆臂的可学习**相对时序**和动量传递机制。对比 CVAE latent、BFM-Zero式目标嵌入、单纯Mimic、AMP与不同接触/时序损失消融。

**验收：** 在未见球位/动作/球员数据上，完整方法优于无人体风格、无接触、只用时间、只用足端、时间反转等强负控制；接触预测必须明显超过**仅训练集触球时间中位数**的时钟基线；全身相位改变可检测、可解释，不能只报小于1mrad的残差。若强基线获胜，则保留负结论并修正研究假设，不改测试集。

### M5：真实物理接触强化学习与全身控制

**任务：** 将M3/M4动作输入经认证的M1小脑、M0真实动力学与完整35D浮动基控制；以本体安全/可达动作/支撑约束阻止非法轨迹，使用真实PhysX足球法向和切向冲量/球速/自碰撞/足底支撑反馈优化。实验前冻结完整训练/验证/测试的球位、速度、种子、任务集和模型检查点。

**验收：** 新动作确实由**新模型输出**在真实 G1 物理里控制29DoF（不是原v32预训练策略射门）；同一14秒真实PhysX中合法正脚背冲量占比≥95%、入门、球速≥3.5m/s、全部原29 `qdot` 在限内、非脚危险碰撞无、真实随挥及落地恢复。历史3.5m/s只是**最低功能门禁**，不能冒充“高爆发”，需额外对相同条件的足球速度/冲量提升做有统计效力的比较。

### M6：论文级独立对照、自然度与可复现交付

**任务：** 完整注册训练/验证/严格留出组（球员、动作片段、球位/球速、有效随机种子；相同球位ON/OFF观测器不是独立物理样本）；相同机器人/资产/预算比较 PAiD旧控制、Standard Mimic、AMP、无 latent、有 latent 无接触、完整方法；预定义完整动作自然度与协调质量盲评，兼顾动作多样性、物理合法率和安全失败类别。

**验收：** 公开协议、代码SHA、逐实验成功/失败与右删失、数值图、控制脚本/环境版本、实际模型权重来源与许可证；报告配对差异和可信区间（以真正独立单位为分母），不选择性展示最好视频。必须完成所有安全门禁后才比较自然性主指标。

## 5. 下一完整研发批次（优先完成 M0 + M1 最小闭环，并行推进 M2）

1. **M0-A 设备与证据**：审计旧v120进程/日志/堆栈和 GPU/磁盘占用，不删除历史进程或数据；分离记录器是否拖慢启动/退出、若 GPU 不可用则改用CPU数据/模型工作。
2. **M0-B native 正负校准**：选择已冻结原G1旧控制、真实足球碰撞阳性及明确分离阴性场景，量测和时间对齐碰撞双方/足底元/根六维状态；输出每条字段及其证据等级。
3. **M1-A Mimic 最小可跑基线**：以已有PAiD 29DoF动作参考和冻结G1真实运行时验证小脑追踪一整段步态/射门动作；报告真动态执行，而不拿输出关节轨迹充数。
4. **M2-A 人体样本资格**：整理合法可用多人的真人射门来源、完整采样帧、真实接触/GRF可用性、分组与归一化；优先修正现有动作起止不全、接触时刻只有代理的问题。
5. **M3-A 小规模latent可复现样机**：在M2已有可用的全身弱监督片段上先运行CVAE vs 无latent/时间打乱，公开负结果，但不因GPU阻塞而假装完成G1执行。
6. **整批交付**：预注册配置/源码SHA、真实的设备/物理运行分母、所有失败、专项测试与可执行复现路径；只推代码+配置+Markdown到GitHub，不推原始C3D/MP4/NPZ/PT或第三方受限数据。

**推进原则：** 一个批次尽量完成「调查→实现→试验→审计→回归→GitHub SHA验证」一整条链；阻塞时诚实完成不依赖该阻塞的实质工作，而不是每一小步都等用户下令。不要因版本数量越来越多而重复制造没有机器人新动作的“研究进展”。

## 6. 完成研究的定义（Definition of Done）

**完成不等于“视频像踢球”或“所有离线损失降低”。** 至少满足：

- 有合格来源的人体全身运动数据及动作示范、明确的真实/代理接触监督边界。
- 新隐空间实际生成多个以前未直接复刻的全身动作，且可在独立动作/球员条件上验证。
- 小脑能在真实自由根G1 PhysX中闭环执行这些动作，控制输出非零、可与原策略区分，接触相位反馈有效。
- 所有安全与功能硬门禁同时通过，且在有效独立球位/种子上报告相对于强基线的变化。
- 在任务合格样本上，自然协调/运动美感的独立盲评优于合理对照；不同运动员动作、姿态阶段、时序与多样性均有客观指标。
- 论文机制有可验证的负控制和消融：移除latent/接触/人体时序/摆臂/支撑反馈时，明确知道效果从何而来；若没有差异，不强行宣称论文创新成立。

本文件随科学证据迭代更新；历史版本与原始失败报告保持不可变，任何新研究路线变更须在新的版本分支明确记录理由、数据和门禁。
