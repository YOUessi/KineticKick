# v0.1.63｜人体足球正脚背运动与动力学数据资格门禁（2026-11-11）

本文件独立于物理试验协议，**不把合成29DoF时序动作、一般体育3D姿态、没有真实脚球接触的CMU片段包装成职业足球正脚背抽射真值**。

## 实际已有、且经本地原始文件校验的数据

- CMU 120Hz 官方文件：2名被试、6段踢球动作，合计3358帧，对应6 C3D + 6 AMC + 2 ASF。本地资格结果见 reports/2026-11-10-v050-real-120hz-soccer-mocap.md。
- 6/6可观测骨架时序；仅10_02与10_05具有可用的连续足球标记运动。
- **0/6**有可靠的专业运动员身份真值、逐帧精确脚球撞击时刻、正脚背冲量、足底GRF/CoP、职业强射球速和足部接触面几何。
- 合成v63轨迹只是执行接口和反例测试：本地源函数 phase_coupled_intent 带肢体耦合，但没有人体监督、专业动作标签或逼真发力链拟合；**论文中只能作为合成先验消融负例**。

**数据准入规则**：来源许可证、参与者与动作身份、时间同步误差、3D标定误差、足/球几何、冲量及身体反力、每个样本的独立被试ID必须逐条审计。未确认前不得混入高质量强射监督集；独立测试按被试和拍摄条件划分，不把同一被试两段动作当独立泛化。

## 后续真正应实现和比较的论文方法（尚未训练）

人体多相位计划 phi(t)：助跑/种植支撑脚/髋外旋储能/躯干反向旋转/摆腿+摆臂/近端到远端发力/正脚背脚球碰撞/随挥/双足落脚/稳定恢复，接触事件应从实测而不是CMU球标记首次运动估算。训练条件包括：

- 人体时序运动的对齐和动态时间规整，不仅对齐角度，还预测相位顺序及受控相位变化率。
- 29DoF实际机器人姿态、角速度、足地约束和力矩可执行层；高层全身动作生成不得通过球状态写入或放宽qdot/非脚终止。
- 需要真实GRF/CoP来做反力监督，现只能将G1 PhysX模拟接触力标记为**机器人物理实测**，不能当人体GRF。
- 多策略对照：原v32、相位波形合成v63（负控制）、CMU弱参考v52、真正学得全身时序（未来）；冻结种子、球位、人体被试分割、29DoF安全与真实触球门禁，并单独盲评运动自然性。
- GPU PhysX原生接触对未证实时，不能对左腕—左髋自碰撞给真值标签或训练“真实碰撞安全证书”；短期只允许安全监测代理、原有硬终止。

目前所有合成姿态幅度/自然度/强射速度改善均是待证伪研究假设，不是成果声明。
