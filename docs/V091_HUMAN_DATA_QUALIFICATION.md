# KineticKick v0.1.91 — 人体数据资格审查（2026-11-12）

目标不是下载最多的动作文件，而是识别真正能监督“专业全身时序协调 + 支撑地面反作用 + 正脚背真实触球动力学”的合法数据。此页是**有界检索**与已存本地证据审查；没有从网页下载原始大文件，也没有凭文章标题宣称已经具有专业正脚背冲量真值。

## 五项最低必需可验证属性

1. 完整连续的髋、骨盆、躯干、摆动腿、支撑腿、对侧摆臂运动，不允许单足/稀疏关键点充当全身动力学。
2. 可靠时钟、被试分组、准确动作类型（全力正脚背射门，而非仅“踢/触球”）和明确数据使用许可。
3. 如欲监督真实支撑动力学，必须有与3D运动同步的左右脚GRF/CoP、力平台或可靠直接测量。
4. 如欲监督真人足—球冲量，必须有验证的实际足球接触起止时间、碰撞位置、球质量以及可核验的冲量/动量改变。足球标记点速度变化**不是**直接测量力。
5. 有多受试者、多动作多场景，并能按被试/运动序列整体分割，绝不把相邻帧拆为独立训练/测试。

## 已验证资料与资格分级

| 资料 | 公共来源与可证实内容 | 当前认可类别 | 不得声称 |
|---|---|---|---|

**严格结论：本轮满足全部五项的真实优秀人体射门训练样本数=0。** GroundLink虽有真正同步GRF和人体姿态，但是否有适配足球正脚背/触球力的合格trial仍未知；尤其不能将人体支撑GRF当作足球冲量。

## 可执行的数据资格门禁与下一数据批次

- 下载前核查许可与数据类型，保存来源URL、许可版本和SHA，不把原始大文件上传GitHub。
- GroundLink先只读取可用列表/试验名称和1个有明确采样率的许可样本：检验marker/GRF时钟对齐、左右脚分力及运动类别。属于**通用支撑先验**，足球接触仍需另采。
- 足球射门数据需要可靠专业运动员数据授权、多视角视频/动捕与实际足球事件标签。若只有视频，训练自然运动学与风格，Impact只能用机器人仿真直接测得且与真人动力学监督严格区分。
- 采用真正分人、分场景、分动作的训练/验证/测试划分；当前单被试来源不足以证明跨被试泛化。
- 若无直接碰撞证据与原G1安全间距，所有新控制策略**只离线**；不能用已有弱残差曲线装作真实高功率射门。

此审查不等于数据已下载，不声称外部许可已逐条通过。
