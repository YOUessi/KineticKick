# v0.1.127 — 原29DoF G1 全轨迹腕—髋碰撞几何下界（冻结协议）

## 固定问题与证据等级

研究问题：在完全不修改原控制器、PhysX环境与历史证据的条件下，按**原始URDF的关节树和全部29个实测关节位置**，能否对同侧腕—髋碰撞候选、左右对称配对与交叉配对的**几何排除条件**进行全时域验证？以200Hz重建原先29回合的81,200帧，报告接触前0.4s、接触后1.25s和至14s恢复全过程。需要区分非脚净力事件和几何候选是否同时出现，不能将相关说成碰撞双方真值。

预先冻结四个配对：左腕/左髋、右腕/右髋、左腕/右髋、右腕/左髋；所有配对同等报告，包含“交叉配对”仅作比较，**不是保证不会接触的负控制**。阈值为0m（碰撞可能的保守包络）和2cm（提前注意区），不在历史数据中调整阈值。必须使用原始锁定URDF碰撞形状的xyz/rpy以及关节的xyz/rpy/axis；不使用link原点距离替代真实几何。

每个圆柱由其自身的轴线段加半径球体得到外包**胶囊体**。圆柱是胶囊体的子集，所以：胶囊间最小表面间隙 **>0** 可以在URDF几何模型内排除该对圆柱的接触；间隙 **≤0** 只能得到“不能排除接触”，绝对不是接触发生的证据；任何几何证据都**不能**替代PhysX真实的USD collider ownership、contact pair / point / normal / impulse真值，更不能证明运行时自碰撞滤波设置。

## 预先冻结的验收

1. Git commit与原始JSON逐文件SHA验证；29回合、24独立条件、5个观察器重复，严禁把OFF/ON重复当独立样本，200Hz每回合2800帧。
2. 对运动学作独立单元测试：零角链、单关节转动、collider rpy、轴向圆柱、平行/交叉/分离线段、退化/NaN拒绝；固定原29DoF命名顺序。
3. 每帧四配对胶囊下界和最近时间；同侧与交叉配对对称报告。不准“看见风险后”修改定义或只选成功片段。
4. 按冻结的触球前0.4s、触球后1.25s、14s其余阶段统计几何风险，并且同时保留现有真实qdot、支撑力**代理**、COM和非脚刚体净力指标，避免误称代理=GRF或真实接触。
5. 在五个匹配OFF/ON对照里逐帧复核几何下界一致性；依赖输入轨迹必须与独立历史SHA相同。
6. 输出每组统计、阴性或不可识别结论、失败图、专项回归与报告。GPU繁忙/空间<20GiB时禁止新增IsaacLab试验。

## 可证伪假设

H0：现有“腕髋自碰撞”事件只能视为等幅反向净力+URDF碰撞形状的候选；即使胶囊体可能接触，也不等于PhysX碰撞双方证据。H1要求另外获得真实PhysX原生contact pair/manifold，再用本批几何推断做交叉验证。在H1之前所有结果标为NATIVE_PAIR_UNKNOWN。

本协议在**分析任何v127结果之前冻结**，历史AG–AN绝不算新的未见物理试验；人体高水平射门动作/GRF/CoP资格仍未通过，禁止让本批程序向G1发出任何动作命令。
