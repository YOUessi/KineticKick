# KineticKick v148 — bounded external human football data qualification (2026-11-13)

**Scope:** Web-published repository metadata; none of the external candidates was downloaded, parsed, contact-verified, subject-disjoint-evaluated, or trained on in this batch. Tang has ~30GiB available and an unrelated long-lived CUDA process. These are *candidate leads*, not accepted ground truth. The six original local CMU clips are independently SHA-verified in v148.

The target supervised action requires at least real human **3D full-body kinematics of strong instep kicks**, accurately aligned **foot–ball contact** (preferably force/impulse and which instep surface), synchronized **plant-foot GRF/CoP**, subject-level split, event timing uncertainty, athlete proficiency and dataset use rights. No listed dataset was found by public description to certify *all* of those properties.

**Training-data admission rule:** Do not call the current CMU clips, EPL 2D poses, SoccerKicks reconstructed joints or a separate GroundLink trial a measured elite kick+contact+force dataset. A valid future dataset must pass *per-subject identity, raw-frame timestamps, dropout mask, 3D sensor calibration, contact annotation uncertainty, actual force plate/ball contact provenance, licensing, and split leakage* checks. A candidate with missing labels is deliberately marked UNKNOWN or TASK-SPECIFIC-ONLY, not silently imputed.

**Proposed actual coordinated robotics method after data qualification:** shared learned phase-conditioned full-body latent for approach → stance plant/COM load → pelvis/trunk initiation → right thigh/shank speed transfer → bilateral arm counter-momentum → **certified right-instep contact** → follow-through → recovery. The robot decoder outputs all 29 DoF plus root and desired contact modes; a constrained dynamics projection must enforce original-G1 joint q/qdot/tau/power, floating-base Newton–Euler dynamics, friction-cone positive normal forces, explicit isolated foot-ground GRF and CoP support polygon, ball-impact manifold legality, wrist/hip distance and native nonfoot-contact embargo, and complete14s recovery. It must train only on train subjects, freeze thresholds/held-out seeds/ball positions before selection, and compare at least no-style, phase-shuffled, no-arm, no-trunk, no-ground-constraint and learned-full-body ablations in actual PhysX. **This is a falsifiable design, not an implemented, trained or physically validated new policy in v148.**

The next experimental work must first secure the native PhysX contact manifold and OFF/ON controller parity; absent calibrated contact and ground-only force channels, prohibit advancing to motor-power or professional-strength conclusions.
