# KineticKick | 真实足球正脚背运动数据资格审查（v0.1.58，有界）

## 目标与可反驳条件

最终训练数据必须让G1学习**助跑—支撑—髋与骨盆扭转—躯干—摆腿—反摆臂—脚背撞球—随挥—落脚恢复**的连续全身协调；只有一个关节姿态匹配指标或足球命中结果不够。为了避免伪标签，严格区分足—球接触真值、支撑足/地面GRF真值、运动学估计与视频推断。

合格的“高质量高速度正脚背射门”样本每条至少记录：明确受试者ID与能力分层、单次完整射门（步态到落脚），采样率及多相机/标记点校准、各足和髋-躯干-上肢运动的时间对齐、正脚背脚部定位与真实撞球时刻，最好同步球速与高频（≥200Hz优先）力平台/接触传感器；必须记录授权与可再分发范围。GRF若只在support foot有力平台，只能标“观测到的支撑足”，不能当双足真值。

## 已有与查到的候选：证据等级

| 来源 | 已核实可得的观测 | 与正脚背强射研究差距 | 决策 |
| --- | --- | --- | --- |
| Tang本地CMU `10_02`、`10_05` | 120Hz C3D人体同一人的动作；球光学标记的运动起点**仅是相位代理**（详见v52已冻结报告） | 缺真实脚球manifold、球速冲量真值、专业受试者强射身份与GRF | **只作为非真值、探索性时序先验**，不得正负样本标签 |
| GroundLink (Han et al., SIGGRAPH Asia 2023) https://csr.bu.edu/groundlink/ | 368条真实人体运动试验、~1.59M帧、标记与同步地面GRF/CoP；下载页包含C3D、SMPL、Force | 涵盖步行/转重/网球挥拍等，**尚未证实包含职业足球正脚背撞球**；不可作为脚球接触标签 | **可作为支撑力/CoM辅助预训练候选**，先核实许可、运动类别与切分 |
| Verheul 等，2024 水平减速研究 https://github.com/JasperVerheul/horizontal-deceleration-forces | 全身运动学/多维GRF和下肢关节动力学，数据Apache-2.0 | 没有高速度正脚背撞球、挥腿/球速同步 | **只适于助跑减速与支撑转换辅助学习** |
| SoccerTrack v2 (2025) https://arxiv.org/abs/2508.01802 | 多机位4K足球比赛、行为类别包括Shot，球场追踪 | **不是实验室3D骨架+脚球接触力/GRF真值** | **只能作检测/视频弱监督候选，不能替代力学真值** |
| 2023足球落地与加速侧移数据 https://data.mendeley.com/datasets/hscscdhg49/1 | 200Hz光学标记、1000Hz地面力平台，声明同步GRF与运动学 | 执行头球后落地/侧移而不是正脚背射门 | **只作为支撑/落脚阶段辅助候选** |
| Wilmes足球IMU/Vicon数据 (2020) https://research.vu.nl/en/datasets/inertial-sensor-based-motion-tracking-in-football-with-movement-i/ | IMU和VICON处理数据及Matlab代码 | 描述为足球运动强度监测，未证实脚背冲量或GRF | **仅运动跟踪辅助候选** |

本次为有限候选搜索与页面级核实，**没有下载并验收新的真实足球射门动捕+GRF+脚球接触同步数据**。本地CMU历史资产不删、不改，不因数据稀缺虚构“专业人体真实射门”。

## 首次训练门禁（须冻结后执行）

拆分受试者ID、采集session、足球球位/场景、实验设备，训练/验证/测试尽量按**受试者与session**隔离。v52-v58已经看过的失败回合只能做诊断/安全回归，不能作为将来未见测试。训练优化的指标区分：(1) 运动协调与自然性独立评价（时序相位、整体动量耦合、盲评）；(2) 正脚背真实接触、射速、出球方向、球门；(3) 原29DoF qdot、非脚刚体真实碰撞、足部支撑、14秒完整恢复。三类都满足才可发表“类人强射”，不在离线余弦MSE或脚部微弱残差层面停止。
