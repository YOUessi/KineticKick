# 2026-10-21 原始 G1 脚板正脚背方向击球验证

## 纠正上一个版本

旧脚法 FRONT (TOE) 主要接触脚板前缘/下缘；不能称为正脚背。原始 G1 只有长约 0.203m、宽约 0.065m、厚约 0.0185m 的平板形脚部刚体，缺少人体的曲面脚背。旧轨迹触球时脚板 TOP 法向主要朝上，并不能作为真正的脚背射门。

## 本次方法与直接证据

不增加任何足球鞋或新的脚部碰撞体。固定基座（仅用于单次接触实验）；足球是 PhysX 物理刚体，球速没有人为赋值。

更新姿态：
- 足踝 pitch +0.64rad
- 髋 pitch 从 +0.20rad 到 -1.05rad 形成大腿前摆
- 膝关节从 1.20rad 到 0.80rad，延迟启动，形成近端到远端的发力顺序
- 足球初始位置 (x=0.15,y=-0.12,z=0.113)m
- 使原始脚板顶部局部法向的世界 x 分量约 0.87～0.89（显著朝前）

18 组 ankle pitch/ball x 搜索中，有多组在第一次碰撞时，足球球心的局部 x、y 落在脚板顶部内部而非前缘以外；x≈0.097m，原始脚板顶部 x 上边界≈0.137m，足背区域仍为平面。该“顶部表面主导接触”是通过相对位置和足部法向进行几何推断，非直接测得的 PhysX 接触点/法向。

## 力度实验

动作执行时间 LOW=0.43s、MED=0.27s、HIGH=0.16s（球体完全接受物理接触，不注入速度）。实测：

| 指标 | LOW | MED | HIGH |
| --- | ---: | ---: | ---: |
| 水平最高速度 (m/s) | 2.530 | 4.170 | 5.952 |
| 接触力峰值 (N) | 110.7 | 203.8 | 320.3 |
| 第一次碰撞后向前速度 vx (m/s) | 1.994 | 3.677 | 5.765 |
| 第一次碰撞后向上速度 vz (m/s) | 0.727 | 1.411 | 2.317 |
| 局部几何分类 | TOP | TOP | TOP |

这说明脚板上表面的正向击球在当前仿真脚型和动作设定下可行，并且三档输入可产生不同的出球效果，尚不意味着真实机器人可达到这些球速。

## Tang 实时 GUI

当前演示：tools/show_g1_power_kicks_v2.py（窗口 KineticKick V3 | TRUE INSTEP + 3 KICKS）。
- 默认停留在 INSTEP (TOP FOOT) 连续播放，让用户容易看到。
- FRONT (TOE) 与 INSTEP (TOP FOOT) 是不同动作，可分别选择对比。
- 可点击 CYCLE 4 KICKS 在 instep_top / medial / lateral / front 中轮播。
- LOW / MED / HIGH 与 CYCLE 3 POWERS 进行力度对比。
- CLOSE FOOT 显示下半身与足球，WHOLE FIELD 显示球门。
- 可以切换与实验性质的 KNEE ONLY 比较发力方式。KNEE ONLY 的力度表现未必随命令速度单调变化。
- 只有不参与碰撞的可视化位置小点，绝无足球鞋碰撞体；全部实时展示在 Tang，不上传 Mac。
- 实时数据：reports/show_g1_power_kicks_v3.log 以及 reports/live_power_kicks.csv。
- 搜索数据：reports/dorsal_kick_search.json。
- 力度数据：reports/dorsal_kick_power.json。
- 共 12 项自动化回归测试通过，其中一项专门验证 TOP 接触几何估计及功率分档。

## 不能误称为已经研究完成

仍是固定根部、预设髋膝踝目标角，不是自由站立、助跑、动态平衡、真人动作模仿训练，更未实现人类脚背的曲面/柔软接触。下一篇论文核心仍是保留从人类视频学习到的身体协调规律，并让动作在物理接触时自然可执行。
