# v0.1.33 球侧冲量：偏门包含切向作用，原控制保持冻结

本版只完成一例预定旧失败条件的只读物理补采，没有新控制器、训练或球上外加冲量。原v32的2800个物理样本、36个接点记录、700个运动学/旧反馈记录及任务结果逐值保持；旧 `heldout_v028_left_near_slow` 仍偏门。P0未完成，v32恢复候选和默认v5不变。

## 确认了什么

在1.600秒之前状态至原出球采样1.625秒之间，球所受冲量如下。坐标为世界x/y/z，射门大致向−Y；正x是向球门右侧。

| 独立读取的来源 | x / y / z 冲量 N·s |
|---|---|
| 右脚法向 | +0.084955900 / −2.369867243 / +0.457314467 |
| 右脚切向 | −0.133987932 / +0.523128648 / +0.028991947 |
| 左脚、其他机器人身体、地面 | 三项各为[0,0,0] |
| 重力 | 0 / 0 / −0.105457506 |
| 实测球动量变化 | −0.049032056 / −1.846739547 / +0.380849309 |

实际球质量0.430000007kg，场景重力z=−9.810000420m/s²，线阻尼0。上表各项与动量变化的向量残差为 **1.0331×10⁻⁶N·s**；固定1.45–1.72秒bin-end窗口的55个5ms采样中，最大单步残差 **1.3907×10⁻⁶N·s**，全窗累计残差1.2686×10⁻⁶。所有规定窗口满足事前0.02N·s工程容差。角阻尼0.05的配置值保留，未把它推算为实测线性冲量。

本回合的法向冲量水平朝向为相对−Y的+2.05308°；加入实际切向冲量后为−1.52088°，与实测出球−1.52086°一致。切向项对应 **−3.57396°** 的向量和变化，向左的切向冲量超过向右的法向冲量。这里是同一回合的实测向量分解，不是假设关掉摩擦后的新轨迹，也不能把偏门全部归因于摩擦：实际法向本身也没有朝向目标中心。

首击前状态中，脚面+Z的水平朝向距目标仅0.967°，但各摩擦锚点位置上的脚端速度朝向偏离目标19.53–19.59°，支持“姿态与扫脚运动未对齐”的运动学描述。点速度由同刻link/COM速度加角速度叉乘力臂得到，不用固定参考点冒充接点。6/7锚点的F·(v足−v球)在该前状态下为负，说明简单的碰前滑移/摩擦同向解释未获支持；SDK作用点与solver阶段尚未知，不能把跨阶段点积当作真实功率、改变已验证力符号或宣称单一因果。

## 原normal-only出球时刻的边界

右脚法向最后非零bin-end为1.620秒，但1.625秒仍有5个摩擦锚点，切向力[1.554537,1.088032,−1.452957]N；1.630秒仍有3个锚点。1.635–1.720秒记录中右脚两类力才都为零。这些尾部bin同样满足动量闭合。因此原1.625秒的normal-only outgoing指标不是所有作用均已结束的证书。本版保留原冻结任务定义与控制分离门控，新增观测语义单独报告。

## 采集错误与显式离线修正

采集器最初对SDK标量加入了未获文档支持的“必须非负”假设，致使四个右脚触球bin标记invalid。原始数组仍保存，24项中9项标量为负。本机API示例直接计算signed coefficient×raw normal；按原符号重建的最大每pair误差3.43×10⁻⁵N，低于固定0.001N，球/足反作用矩阵之和为0，且无容量/索引/非有限数据问题。

原采集源码、raw报告和严格拒绝报告均保留。新审计必须显式加 `--decode-signed-raw`，在同一保存数据上重新检查各pair、normal和friction独立范围、原probe符号、反作用及动量；不取绝对值、不翻法向、不拟合符号或阈值。原acquisition flag仍为false，补充的offline reconstruction/impulse diagnosis通过。另一原审计差异仅为probe相对/绝对路径，只有解析到相同实际文件且SHA一致才记录为元数据例外。

## 研究判断与下一步

三个旧条件的19个有载接点可由原七capsules几何精确重建，但最近/最深接点和最快接近点均不能代表有效首击法向。应停止这种标量选点纠偏。新方向控制需要处理实际身体状态、触球位置/曲面与摆脚运动方向的协同，不能仅给脚面追加yaw或按单球位调参。v32新扰动的错误触球也要求在改变出球方向时重新核验正脚背与恢复，而不能继承旧成功标签。

P2的MUVY多视角素材完成两次有界相机假设检查，均未通过预留点验证，没有生成可信度量人体3D。见 `docs/research/2026-11-07-muvy-camera-feasibility.md`。这些未知数据未被用于训练，也不声称完成P2/P3/P4。
