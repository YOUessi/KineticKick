# v0.1.164 真人全速动作跟踪、正脚背射门与恢复

从 v0.1.163 的 `9648b710` 创建独立版本分支。所有下列回合使用 Tang 的 SAPIEN 3.0.3 CPU PhysX、原 G1 29 轴、自由基座、原碰撞体和原执行器硬限制。一个回合包括 2,800 个 5 ms 物理步，50 Hz 控制。从初态开始，整个回合没有写入基座、关节或球状态。球的出速与方向取自模拟碰撞后的实际速度。数据来自两个 CMU 被试，球员竞技水平、人体冲量及地面反力未获确认。本版沿用已发布的 GMT 权重与六个腕轴的参考跟踪，通过控制输入、初态及接触后关节目标修正执行动作。

## 原速跟踪

10_06 的前兆在首步就出现。右腕与髋相碰，换步时又发生双膝碰撞，3.870 s 测得 660 N，随后承重侧与源动作不一致，4.610 s 骨盆跌破 0.45 m。仅避开右腕仍会跌倒。只改双臂间隙可以保持直立，却仍有膝间碰撞和个别关节越界。对重定向参考的肩部作几何修正，同时把参考与实际骨盆的水平速度、位移和朝向误差送入跟踪器，原速完成了 4.76 s 源片。原脚底参考保留，全部速度、关节及支撑约束按实际物理测量。

### 10_05 的侧移从哪里开始

在原通用控制器下，10_05 的主要失衡发生在左肩撞躯干之前。2.20 s 骨盆已偏出参考约 10 cm，2.90 s 横向实际速度 1.07 m/s，参考为 0.20 m/s。去掉额外步幅速度前馈并保留原有位姿反馈后，完整走完同一段动作，无危险非足接触，末段站稳 7.970 s，骨盆世界 RMSE 从 41.14 cm 降为 17.1 cm。以实测速度连续降低该前馈的对照同样能恢复，末段站稳 8.315 s。

两种候选均用固定参数回放同一组六段。两套都全程无跌倒、没有关节位置或速度越界并在末段站稳，但 10_03 的右腕在 2.76–2.78 s 与右髋发生 32.39–38.33 N 的碰撞，严格结果均为 5/6。原设置、取消额外步幅、随速度衰减三套方案的六片平均骨盆世界 RMSE 分别为 27.0、30.2、34.3 cm。它们的失败动作与跟踪代价均保留。

### 最终共用控制器通过 6/6

在零额外步幅前馈的基础上，对同侧腕与髋的原始胶囊体计算实测间隙和闭合速度。预测即将发生接触时，修正肩部目标使腕向外让位。该机制消除了 10_03 的右腕撞髋，六段都站稳，但 10_01 右踝在 5.680 s 超限 0.00002267 rad。200 Hz 驱动指令显示，该踝在上下界附近快速反转，35 ms 外推已经越过另一侧保护区时，保护器给出相反的大幅制动指令，下一步反弹回原限位。加入一个方向判定：当关节当前贴近一侧且外推跨过两侧保护区时，停用这一次反向补偿，执行已有的受限 PD 驱动。物理硬限、惯量、碰撞体和力矩上限均沿用基线。

同一冻结配置与启动规则跑完全部六段，不使用动作编号选择控制器。已知失败片参与开发，六片属于现有资料上的回归，尚需独立的新动作测试。每段均具备七项完整检查，无跌倒、无危险非足碰撞，无角度和速度越界，连续恢复双足站稳。按原参考时钟配准，六片骨盆世界轨迹 RMSE 平均 23.58 cm。

## 两条实测射门与固定球门扰动

10_02 的基线横向轨迹误差为 37.51 cm。触球后的落脚反馈按实际足底载荷和骨盆速度修正髋膝目标，保留同一击球。骨盆三维 RMSE 从 37.78 cm 降至 34.20 cm，偏航 RMSE 从 13.56° 降至 7.51°，全身相对姿态误差从 2.96 cm 增至 3.82 cm，双足站稳从 8.175 s 缩短至 7.085 s。这个选项保留为实验分支，关闭时 v163 的 18 个物理数组和原生接触流完全复现。切换跟踪器、虚拟支撑力矩及提前制动等方案的结果留在 Tang 的开发目录。

10_05 用源球标记注册世界球位。PAiD 在相同场景 1.075 s 发生右腕与髋碰撞，2.905 s 跌倒，没有触球。沿用 10_02 参数或仅移动击球相位均未完成任务。在修正进场和支撑后，右脚能射进并站稳，最初随挥只前进 17.31 cm，扣除骨盆平移为 6.54 cm。改为实测右脚首次加载后才触发的前摆与回收后，右踝前移 29.02 cm，相对骨盆前移 15.42 cm，120 ms 时向前速度为 0.80 m/s，240 ms 后才开始持续反向。2.580 s 首触、3.580 s 整球过线，首触前脚尖朝下 31.33°。四种原生接触点与足面分类口径均为 100% 正脚背。该片全段骨盆世界 RMSE 32.56 cm，源片末帧水平误差 79.35 cm。冻结后完整复跑与开发成功回合的全部 18 个轨迹数组、2,800 步原生接触记录一致。[注册场景、足面核查与射门复跑命令](2026-11-14-v164-second-human-shot.md)

## Tang 复现与预览

在项目根下执行。原始 CMU 数据、原 G1 资产及 GMT 检查点位置沿用 v163。输出目录需为新路径。

```bash
export PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 CUDA_VISIBLE_DEVICES=
phys=/home/you/conda_env/maniskill/bin/python
clip=11_01
loc=experiments/v164_repro
mkdir -p "$loc"
/home/you/conda_env/env_isaaclab/bin/python -s tools/v164_clear_reference.py \
  --input "experiments/v162_human/references/$clip.npz" --output "$loc/$clip.npz" > "$loc/$clip.json"
"$phys" tools/v164_clear_wrist.py --reference "$loc/$clip.npz" \
  --config configs/v164_clear_braking.json --initial-state-config configs/v164_initial_braking.json \
  --output "$loc/tracking_$clip"
/usr/bin/python3 tools/v164_support_score.py --run "$loc/tracking_$clip" \
  --reference "experiments/v162_human/references/$clip.npz" --clearance "$loc/$clip.json" \
  --output "$loc/tracking_$clip/score.json"
"$phys" tools/v163_gmt.py --reference experiments/v162_human/armclear/10_02.npz \
  --drive native --settle --feedback 2.5 --ball 1.18723 -0.80613 --direction 0.9978 0.0663 \
  --adapter configs/v163_human_10_02.json --landing-controller configs/v164_follow_step_10_02.json \
  --lateral-ball-offset 0.015 --output "$loc/shot_10_02_left"
/usr/bin/python3 tools/v161_evaluate.py --run "$loc/shot_10_02_left" --output "$loc/shot_10_02_left/score.json"
/usr/bin/python3 tools/v161_surface_audit.py --run "$loc/shot_10_02_left"
```

Tang 上的 14 s 实测视频为 `media/v164_human_10_06_shared_tracker.mp4`（通用跟踪）、`media/v164_human_10_06_comparison.mp4`（专项跟踪）和 `media/v164_human_10_05_shot_full_field.mp4`（完整射门）。左侧为同场景旧控制，右侧为修复后的回合，下方小窗是重定向参考。无须下载人体原始文件即可在 Tang 打开已生成的视频。原始 200 Hz 轨迹、接触流、训练候选和参数摘要保存于 `experiments/v164_support`、`v164_clear`、`v164_initial`、`v164_landing` 和 `v164_strike`。
