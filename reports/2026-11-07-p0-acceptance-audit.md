# P0：v0.1.28 保存物理证据复核（2026-11-07）

**结论：原冻结任务结果可复现，但 P0 的“连续随挥、无性能回退、全部论文验收完成”不能成立。** 15 个已有条件从 v27 的 14/15 提升为 v28 的 15/15；预先声明的 3 个新条件只有 1/3 完整成功，另外两个明确保留为射门偏出。新增审计发现 `initial_slower_02` 的落脚速度/冲击回退，以及身体携带与腿相对随挥之间的明显差别。

本次只读取既有报告、源代码和本地 URDF，未启动仿真、训练或 GPU，也没有修改控制器、冻结验收、19 个冻结资产或旧版本。实现是 `tools/audit_p0_dynamic_strike.py`，生成数据是 ignored 文件 `reports/p0_v028_acceptance.json`。后者保存逐条件对照、原始量纲、来源 SHA256 和重点事件的完整 ±0.1 s 证据。

## 原冻结验收与证据边界

- 18 份 v28 和 15 份 v27 原始报告的 SHA256 均与已发布 `reports/v028_final_comparison.json` 一致。33 份原始任务 summary 全部重算一致，`ShotTracker` 对接触、进球和站稳的回放也与记录一致。
- v28 配置内 **19/19 冻结文件**、比较报告内 **10/10 执行源文件**、包括上游 soccer 源码树在内的冻结 runtime 来源全部复核一致。报告保留原资产、自由根、目标尺寸、初始机器人姿态、执行器 effort/velocity limits、终止策略和接触采样配置；无 post-initialization state writes 的记录标志一致。
- 源码中原 G1 使用 `fix_base=False`、`enabled_self_collisions=True`、`replace_cylinders_with_capsules=True`；球的 pose/velocity 写入位于初始化，机器人外力/推力随机事件关闭。**这些是来源与记录契约证据**；历史报告没有逐次 state-write/外力调用日志或 runtime collision-filter 快照，因此不升级成独立运行时证明。
- 18/18 v28 条件具有正确右脚接触，重新分类的 instep impulse fraction 均为 **1.0**；记录的非脚身体碰球事件数为 0，最大 nonfoot 净接触力记录为 0 N。所有接触的 pre-integration frame 重建通过，局部接触点误差最大 **2.26e-7 m**、法向误差最大 **3.00e-7**。这支持现有合法脚面判据，不等同于人类脚形/自然度验证。
- v28 出球水平速度 **3.923–5.525 m/s**，最终站稳 **5.990–10.395 s**。全部运行保存 14 s 物理窗口；两个新条件的站稳不抵消其进球失败。
- 配置限值保持不变，保存的 torque estimate/effort limit 最大比值 **1.0**，velocity target/velocity limit 最大比值 **0.375**。但**实际关节速度并非始终在限值内**，见下一节。torque estimate 是隐式执行器 clipped-PD 估计，不是硬件扭矩测量。

## 第一优先回退：`initial_slower_02` 落脚事件

在 v28 **1.850 → 1.855 s** 的一个物理步内：

| 观测量 | 1.850 s | 1.855 s |
|---|---:|---:|
| 右脚 ground-filtered force（N） | 0 | 4697.75 |
| 右膝位置（rad） | 1.0294 | 0.9996 |
| 右膝实际速度（rad/s） | -6.3759 | **38.0518** |
| 右膝位置目标（rad） | 0.6718 | 0.6718 |
| 右膝速度目标（rad/s） | 0 | 0 |
| 右脚记录点速度（m/s，世界 xyz） | [0.460, -1.891, -2.291] | [-3.005, 16.821, 0.884] |

该步右膝实际速度达到记录限值 20 rad/s 的 **1.9026 倍**。脚点速度向量跃变 **19.2934 m/s**，5 ms 有限差分峰值加速度 **3858.68 m/s²**；对应 v27 同条件的整个接触后窗口最大脚点跃变仅 **2.4731 m/s**，所有关节的最大速度限值比为 **0.9083**，无实际超限采样。

**已核实的区分：** v28 1.850 与 1.855 s 的全部 29 个关节位置目标、速度目标逐项完全相同；1.76–1.94 s 的 hip-brake、shank/ankle correction 均为 0 且 inactive。因此该 5 ms 箱没有新增控制目标跳变或直接制动修正。冲击同时伴随右脚落地力脉冲，支持“与落脚接触事件同时发生”的定位。1.845 s 则已有上一个 20 ms 控制更新（右髋目标 -0.1295→0.2275 rad，右膝目标 0.7821→0.6718 rad），它可能影响落脚状态，但尚无因果消融证据。

v27 对应落脚过程较早：1.835 s 右脚力 137.90 N，1.840 s 1633.00 N，1.865 s 2346.64 N；没有同样的右膝速度超限。v28 的首次出球采样为 1.690 s，v27 为 1.645 s，所以相同绝对时刻并非相同接触相位。保存报告同时保留原时间与接触时间，不能把两段机械地对齐后解释为因果差异。

**根因仍未确认。** 历史地面遥测是力的标量汇总，不能分离法向/摩擦、冲量、约束求解器作用，也不能证明早期适配器、IK 投影或落脚姿态中哪项造成回退。下一次最小诊断应优先复现此条件，并补充地面接触法向、切向/摩擦冲量和接触点，不先扩大搜索或改验收。

另外 3 个 v28 条件有实际速度超限采样：`combined_left_slower`（2.615 s 左髋 yaw，32.771/32 = 1.0241）、`heldout_left_near_slower`（2.250 s 右膝，20.989/20 = 1.0494）、新条件 `heldout_v028_near_slow_17`（2.315 s 右踝 roll，43.074/37 = 1.1642）。这些保留为动态诊断回退；不改写已经冻结的原任务成功定义。

## 连续随挥：身体携带与腿相对运动

审计分别计算目标水平轴、第一接触 episode 的冲量加权接触法向水平轴。两轴夹角为 **0.027–18.463°**。位置采用 20 ms 的实际足姿：既保存 ankle-link 原点，也用足姿旋转构造原记录点 `[0.06, 0, -0.025]`；速度跃变另用 5 ms 保存的实际脚点速度。没有把球已飞出或 phase label 当作随挥证据。

以**首次分离采样后** 250 ms、目标水平轴、记录脚点为口径：

- 世界前向最大位移 **0.355–0.633 m**；减去骨盆平移后，最大相对前向位移仅 **0.045–0.156 m**。
- 分离后 120 ms 的相对前向速度 **-0.501–0.413 m/s**；250 ms 时的相对净位移 **-0.193–0.055 m**。其中 17/18 在 250 ms 时相对骨盆已回到分离点后方。
- 相对骨盆的首次持续反向出现在 **60–180 ms**。定义是连续至少 40 ms 的离散差分速度低于 -0.15 m/s；“停止”另以绝对速度 ≤0.15 m/s 连续 40 ms 报告，缺少此类区间时保留 null。它们都是描述性诊断阈值，不是事后追加的冻结验收。
- 正确 pre-integration 足姿的接触冲量加权 top-axis·goal 为 **0.669–0.825**，toe 世界 z 为 **-0.826–-0.670**。这与合法 instep 分类是不同量，不能互换。

现有 `tools/follow_through.py` 的额外诊断也被原样运行：世界推进 ≥0.22 m、骨盆相对推进 ≥0.15 m（首接触后 250 ms）、120 ms 前向速度 ≥0.60 m/s、持续反向不得早于 200 ms、后撤速度/晚接触及 posture 门槛。**v28 只有 1/18 通过此额外诊断**（`heldout_right_near_faster`）；17 个条件相对 swing 不足，8 个还未通过其更严格 posture 门槛。v27 14 个有接触条件也只有同一个条件通过；无接触的第 15 个条件不计作可测随挥。

上述 0.15 m、posture 等阈值并非 v28 冻结成功条件，也不是经过标定的人类自然度标准。现有诊断的 ankle-origin/首接触口径，与本报告 tracked-point/分离采样口径不同，因此各自数值分开保留。正的世界前向速度并不能证明腿相对骨盆连续向前摆；这些有限采样也不证明连续时间平滑性。避碰制动可能限制随挥是待验证假设，不能从相关性定论；本次主要冲击事件窗口内该制动并未激活。
