# v0.1.16：可直接选择的短助跑挑球

本版将已有v0.1.9短助跑挑球整理成单独配置，并在当前Tang环境重新录制完整物理回合。复用原控制器、策略、球和29DoF G1，不把它描述为新完成的连续跑动挑球。

## 新录像实测

- 2.405秒由脚内侧直接触球，球在脚部受力时获得向上速度；没有小腿/身体碰球。
- 首次飞行球心最高0.421m，球底离地0.311m；持续腾空0.500s，2.940秒首次落地。
- 球进门，7秒回合末段连续站稳3.92s；无摔倒、非脚部接触或自动重置。
- 起球速度约5.84m/s，其中竖直分量约2.13m/s。这里是小挑球示例，不是指定高度定点或轻中重标定。

机器人自由运动，所有初始状态写入只发生在初始化。没有额外球冲量、改变球质量/重力或扩大执行器上限。挑球来自真实脚球接触与向上随摆。

## 使用

```bash
/home/you/conda_env/env_isaaclab/bin/python tools/lofted_shooting.py \
  --config configs/chip_shot_v1.json \
  --output reports/new_chip.json --video-dir media/new_chip_frames
```

配置默认选择`loft`。不传`--video-dir`时入口使用GUI预览；无窗口只测量可加`--headless`。新配置中的控制参数与实际录像所用`configs/lofted_shooting_v1.json`的`loft`试验逐项相同，原配置和所有旧入口保持不变。来源配置、最终报告指纹及适用范围均记录在`configs/chip_shot_v1.json`。

最终报告：`reports/v016_short_run_chip_preview.json`。预览：`media/chip_short_run_v0.1.16.mp4`，7秒正常速度加同回合5.6秒近景慢放。

## 连续跑动挑球的边界

本轮也尝试把挑球迁移到当前连续移动射门流程，但三个有界候选均未通过，未发布为可用模式：

- `v016_inside_lift_candidate.json`：球心最高约0.263m，恢复阶段触发非脚部碰撞。
- `v016_inside_early_lift.json`：提前发力后能恢复站稳，但触点更靠近球心，球心最高约0.230m且未进球。
- `v016_inside_under_ball.json`：按接触几何调整后的动态回合出现小腿碰球；静态间隙可行不能替代实际动态验收。

连续跑动中不停步挑球仍未稳定。三个失败报告保留在ignored本地目录，没有放宽合法触球、飞行或站稳条件。按用户快速跑通的要求，停止继续扫描此路线，优先提供已验证的短助跑挑球。

没有新训练、完整CPU回归或大型扰动矩阵。发布依据为一次新的完整7秒实际渲染回合、已有飞行判据、整体进球/恢复验收和配置来源一致性检查。

本版使用独立`version/v0.1.16`分支，从已推送的v0.1.15建立，保留main和全部旧版本。上游源码、权重、原始动作和生成媒体仍遵守`VERSION_CONTROL.md`及.gitignore的本地资产约定。
