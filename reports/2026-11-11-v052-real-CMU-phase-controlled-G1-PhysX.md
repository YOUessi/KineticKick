# KineticKick v0.1.52 — 真实 CMU 120Hz 人体相位先验 → G1 29DoF 参考 → 真实 PhysX 严格验收

**版本基础：** `version/v0.1.51` (`d483886`)。本批次创建 `version/v0.1.52`。
**实验性质：** 两个真实人体 CMU 动捕片段均来自同一人；光学球体标记连续出球只能提供推断运动起点，不能提供真实脚-球碰撞或专业正脚背高冲量力学真值。本研究不把姿态代理得分称作自然度，也不把一次进球称作真实类人爆发抽射。

## 1. 从上一轮到本轮的真实算法变更

- 使用原 CMU `10_02`、`10_05` 两段 120Hz 骨架，经 v0.1.51 已审核 8D→6D 跨本体共享的几何方向余弦。分别以光学球标记速度起点为人类相位零点，以原 G1 接触力首触作为 G1 物理相位零点，两者**并不是真实同步触球**。
- 建立保持梯度的可微 G1 29DoF URDF 正运动学六通道映射，数值与 v51 冻结基线正运动学一致；各人体片段围绕自身初始姿态提取相对时间变化，经 `relative_gain=0.14` 加到原真实 G1 已执行射门参考，而不复制人体骨长/绝对关节角。
- 每个片段只执行事前固定的 96 步投影优化，约束左支撑脚、右摆动脚、关节位移、相邻时刻平滑性与足/球接触前提前关闭；`700×29` 控制参考满足 0.006rad 振幅、每20ms 0.0012rad 变化上限及原 URDF 关节范围。
- **没有训练新 PPO 或生成真实人体动量/冲量。** 将两条不同参考分别交给原 v41 独立 STYLE 激活通道；原 G1 脚球碰撞、PD 电机、相同足球初态、真实速度约束、v32 射后平衡策略均不修改。
- 运行额外禁用新参考的 ZERO 物理对照；原始 2800 步物理变量与 v32 基线在共有字段上逐值一致。旧 v32 还记录了 7 个新评估器未输出的附加遥测字段（未伪造），因此不能宣称完整 JSON 字节相同。

## 3. 关键负结果：10_05 在 5.14 秒失败

- `10_02` 完成 700 个控制步 / 2800 个真实 5ms 物理步；动作实际变化峰值约 1.30mrad，原物理任务和站立完整通过。
- `10_05` 在 **5.14s** 左右触发 `physical_nonfoot` 非脚部接触终止：仅执行 257 个控制步 / 1029 个物理步，`standing_seconds=0`；即使此前已进球，完整任务不合格。该失败没有被凑成700步或补出缺失物理状态。
- 两组物理六维人体相位代理 MSE 变化为 `-0.000001180` 与 `-0.000001580`。变化极小且不是人体自然度，更不足以抵消 10_05 的真实跌倒。
- 无单独重复随机种子，无法确定动力学敏感性/参考差异在统计上的鲁棒性；此次不能推销为“人类爆发抽射学习成功”，更不能升级正式控制器。

## 5. 与最终论文目标的差距及下一个有科学价值的批次

1. **输入证据不足。** 需要有精确脚球接触时刻/脚面姿态、左右支撑、骨盆-躯干-踢腿-摆臂全身相位及真实球速/旋转的数据；目前的CMU两条样本只是单人的光学球体运动代理，且未知是否属于顶级球员大力正脚背抽射。
2. **风格与安全必须联合建模。** 当前不是一个能主动维持射后平衡的条件动作生成器。下一版应把相位先验和真正可物理实现的动作/触球/射后恢复结合，在相同足球状态测 `t_contact−0.4s` 到 `t_contact+≥1.25s` 的qdot、支撑切换、根姿态、实际冲量和非脚部接触；保留 10_05 为失败回归案例，不能调参后将同一案例称作未见测试。
3. **独立验证自然度。** 需要按人/球位/动作类型划分数据，在固定任务成功与安全前提下做匹配的盲评对照，比较模仿策略、通用风格奖励与明确相位协调先验；进球率仅是功能门禁而不是论文主要创新。
