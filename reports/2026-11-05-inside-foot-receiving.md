# v0.1.19：脚弓停地面球与高空球实验

用户选择两种来球都尝试，并要求主动卸力。本版本增加地面传球和高空球两种脚弓接球场景、来球预测、提前回撤、有限接触回让和低球速/低自转触发的恢复。**两种场景的完整“停住球并恢复站稳”均未通过**，不作为已完成的停球模式发布。

## 两种来球的实际进展

保留的同一版控制入口为`tools/run_inside_receive.py`；其源码与下面两份实际渲染报告的控制指纹一致。两种场景均从准备好的单脚支撑姿态开始，不包含走向来球或在线寻找落点。

| 项目 | 地面传球 | 高空来球 |
| --- | --- | --- |
| 配置 | `configs/inside_receive_ground_experimental_v1.json` | `configs/inside_receive_aerial_experimental_v1.json` |
| 本地物理报告 | `reports/v019_inside_ground_compliant.json` | `reports/v019_inside_aerial_compliant.json` |
| 来球 | 初始滚动速度1.20m/s，初始化匹配滚动自转 | 实测最高球心1.043m，带水平速度的抛物线 |
| 首次脚弓接触 | 0.680s | 0.690s，早于首次落地0.835s |
| 脚内侧接触冲量占比 | 100% | 100% |
| 触球前脚部测点沿来球方向的速度 | 0.359m/s | 0.733m/s |
| 首段碰撞前后球速 | 1.188→0.566m/s；包含地面作用 | 5.665→1.432m/s；均在落地前测得 |
| 恢复开始时球速 | 1.040s时0.016m/s | 0.920s时0.068m/s，已经落地 |
| 完整结果 | 末段连续站稳2.780s，但收脚再次推球；最终球速0.246m/s，距离根部0.882m | 恢复时再次推球并失稳；3.015s出现左小腿碰球，随后终止 |
| 完整停球验收 | **失败** | **失败** |

回撤速度来自固定在右脚原生内侧胶囊表面的测点，沿实测来球速度投影，不是单纯的脚尖下移速度。接触分类继续使用原有脚面法线/接触位置规则，没有放宽脚内侧标准。球面点经碰撞间隙和碰撞前姿态还原到脚表面，最大胶囊表面残差分别约3.90e-8m和3.80e-8m。

低球速只是中间阶段证据。地面球后续滚走、高空球后续非脚部碰球，都使完整验收失败。没有用旧射门分数作为停球分数。

## 具体控制变化与当前缺口

原先给定相同的起点和触球位置、却要求终点具有回撤速度的插值，会先向来球方向运动再回撤。新预测把触球前的回撤位移计入拦截平面，避免这段反向迎球；位置和速度目标连续生成，通过原有关节电机执行。

接触后记录沿来球方向的实际回让，允许目标位置随冲击后退，最大4cm，避免位置控制立即把脚弹回球上。恢复同时检查球的平动和自转；有最大等待时间，避免一直单脚等待。所有补偿都是普通关节位置、速度和力矩命令，没有改变球或机器人物理状态。

剩下的主要问题在恢复衔接：球已经显著减速，但直接交给站立策略会再次带到球。额外尝试了先把脚移开再恢复，球可保持约0.009m/s，交接时球与脚胶囊间隙达到6.65cm；然而延长的单脚阶段导致身体继续偏移。进一步提前交接支撑腿和躯干，仍在恢复阶段发生小腿碰球。**分离脚与球尚未和可靠的全身平衡统一起来。** 这些失败扩展只保留在本地实验快照，没有替换两种场景均实际运行过的发布入口。

本轮停止继续扫描时间和姿态参数。下一步应围绕接触结束时的身体速度、支撑区域和安全落脚位置设计恢复过渡；当前结果不能证明G1本体不能停球，也不能证明任意来球已可控。

## 保留的试验

本轮共7个有物理数据的有界回合；另一个高空录像启动在物理回合前停止，修正旧射门框架的球门距离约束后再试。无训练、无宽泛参数矩阵。

| 本地报告 | 结果与诊断 |
| --- | --- |
| `v019_inside_ground_pilot.json` | 真实脚弓接触，无其他部位碰球；回撤仅0.027m/s，球滚走。 |
| `v019_inside_aerial_physics.json` | 首次空中脚弓接触，无其他部位先碰球；回撤偏晚，等待低球速过久，1.90s高度终止。 |
| `v019_inside_ground_flat.json` | 修正脚弓姿态后提前回撤成立；球仍反弹，迟迟未恢复，2.075s小腿碰球。 |
| `v019_inside_ground_compliant.json` | 发布的地面实验：提前卸力，短暂近乎停住；恢复站稳，但再次推走球。 |
| `v019_inside_aerial_compliant.json` | 发布的高空实验：空中脚弓提前卸力；恢复阶段再次推球、失稳。 |
| `v019_inside_ground_release.json` | 球停住、脚成功分离，但恢复身体偏移，1.750s右小腿碰球。 |
| `v019_inside_ground_support.json` | 提前交接支撑腿和躯干仍未恢复成功，不再重复同类调参。 |

各阶段的计划、源码快照、原始遥测和帧都保存在ignored的`experiments/inside_v019`和`reports`目录。失败没有删除或重标为通过。

## 复现与预览

```bash
/home/you/conda_env/env_isaaclab/bin/python tools/run_inside_receive.py \
  --plan configs/inside_receive_ground_experimental_v1.json \
  --output reports/new_inside_ground.json --video-dir media/new_inside_ground_frames

/home/you/conda_env/env_isaaclab/bin/python tools/run_inside_receive.py \
  --plan configs/inside_receive_aerial_experimental_v1.json \
  --output reports/new_inside_aerial.json --video-dir media/new_inside_aerial_frames
```

两条命令复现的是实验场景，不是通过验收的停球技能。参考缺失时，可以使用已有`tools/prepare_aerial_reference.py --plan <上述配置>`从配置中的明确准备姿态重建；生成器拒绝覆盖已有参考。配置记录数值报告、原始测量计划、源码、参考、模型和资产的SHA-256。发布配置只增加状态和证据元数据，控制参数与记录的原始测量计划相同。

预览：`media/inside_receive_experimental_v0.1.19.mp4`。依次展示地面和高空回合的正常速度、触球慢放，明确标注未通过；使用真实物理帧，保留恢复失败过程。

## 验证与限制

6项针对性CPU检查通过：地面/空中判定隔离、落地前减速要求、拒绝被动挡球、拒绝非脚部接触/残余自转、提前回撤与拦截一致、接触回让有界且不反向弹回。未运行完整套件或扰动矩阵。

机器人自由根部、原始29DoF本体、球质量与半径、接触材料、关节限制和执行器上限保持原样。球的位置、线速度和初始滚动自转只在开始时初始化一次；记录中`post_initialization_state_writes=false`。未新增脚部碰撞体，未关闭碰撞，没有外部球冲量。

完整运行仍依赖Tang-local原始URDF、上游动作、ONNX、仿真器和本地资产，GitHub的新克隆不自包含这些文件。本版本保留原射门、挑球和v0.1.17/v0.1.18接球源码与配置。
