# v0.1.18：提前随球下撤的控制实验

用户强调“要懂得卸力”。本版本把接球从高度阈值触发的关节姿态改为来球预测、连续的脚部位置/速度目标、实际速度反馈以及接触后的恢复交接。**完整脚背停高空球仍未通过**，不替换v0.1.17可用的接触与站稳预览，也没有验证连续颠球。

## 已核实的进展

保留的固定来球试验是`reports/v018_lag_recovery_preview.json`，参数为`configs/aerial_cushion_experimental_v1.json`。自由根部、原始碰撞体、球质量/半径、关节与执行器限制不变。球仍从`[-0.121762149,-0.85,1.05]m`、速度`[0,0.75,0]m/s`初始化一次；之后无机器人/球物理状态写入或额外球冲量。

- 0.380s首次脚背触球，之前没有身体碰球。
- 触球前脚部测点已向下运动0.351m/s；v0.1.17同一测点在触球前仍向上运动0.323m/s。测点是固定在脚坐标系的`[0.06,0,-0.025]m`，不是随每个接触点变化的表面点。
- 触球前球速3.754m/s，0.405s时1.213m/s，下降67.7%；均在地面接触前测得。脚背接触冲量占比100%。这是提前下撤的阶段性证据，不是完整停球成功。
- 0.420s启动站立策略交接，0.450s仍出现右小腿碰球，回合在0.460s终止。`anticipatory_foot_lowering=true`、`cushioned=true`，但`success=false`、`unintended_body_ball_contact=true`。

## 原因与控制变化

旧指令只降低脚的位置；离球最近的部分出现约3cm到18cm的IK位置残差，说明目标已不可达。同时没有关节速度前馈，实际下撤响应滞后。新轨迹让支撑腿适度下蹲，为下撤留出行程，连续生成脚部位置、速度和旋转速度；用真实关节速度误差补偿正常关节力矩。没有修改物理引擎的刚度、质量、摩擦或碰撞规则。

来球的位置和速度用于预测下降交点。接球脚在碰撞前抬起脚尖，按足部胶囊端点几何选择目标位置，然后顺着预测速度下撤；恢复阶段按真实触球时刻触发，并保留展开的手臂。计划中显式记录40ms指令提前量，补偿本轮观察到的响应滞后。

实际触球时仍未保持计划的球脚相对位置和接触方向：计划法线的世界Y分量约-0.192，第一段实测冲量加权法线Y分量为+0.0288，Z分量为0.9995。球的水平速度没有被控制住，仍朝机器人和小腿方向移动。因此，提前下撤和单次速度下降都不足以证明完整卸力停球。

下一步需要接触几何和球脚相对运动的闭环约束，以及接触过程中的柔顺控制与避碰撤腿。当前结果不支持继续仅扫描姿态/时间参数，也不证明G1硬件本身无法完成停球。

## 有界试验与保留的失败

| 本地报告 | 实际结果 |
| --- | --- |
| `v018_predictive_cushion.json` | 位置/速度预测与支撑腿协同已接入，但0.395s小腿先触球。 |
| `v018_velocity_feedback_preview.json` | 增加速度误差力矩反馈，脚已提前下撤，但0.405s小腿先触球。 |
| `v018_instep_cushion_preview.json` | 提高接触点并抬脚尖，0.380s首先脚背触球；0.535s二次小腿触球，0.915s手腕/大腿碰撞。最终球速低不算通过。 |
| `v018_lag_recovery_preview.json` | 补偿滞后并调整恢复，首次触球前下撤成立，0.450s二次小腿触球；完整失败。 |
| `v018_settled_arrival_preview.json` | 不改控制器，球先抛起、最高点和下降路径与前一试验相同，晚0.35s到达；0.780s仍小腿触球。初始化回摆不足以解释问题。 |

最后一个隔离试验仅改变初始抛物线，没有中途“发球”状态写入。所有失败报告、帧、计划与源码快照保留在Tang的ignored目录。本轮没有新训练，也未运行大规模参数矩阵。

## 复现及检查

```bash
/home/you/conda_env/env_isaaclab/bin/python tools/run_aerial_cushion.py \
  --plan configs/aerial_cushion_experimental_v1.json \
  --output reports/new_active_cushion.json --video-dir media/new_active_cushion_frames
```

该命令复现的是**实验失败案例**，不是完成的停球模式。参考若缺失，可用已有`tools/prepare_aerial_reference.py --plan configs/aerial_cushion_experimental_v1.json`重建；该工具拒绝覆盖现有参考。源码、参考、模型、资产和实测报告的指纹保存在配置中。保留的控制器和轨迹生成器源码与选定报告中的SHA-256一致。

3项新CPU检查通过：下降交点、已经错过的交点、连续轨迹的位置/速度一致性。未跑完整测试套件，原停球判定及旧射门源码均未修改。完整运行仍需要Tang-local模型、原始URDF、动作与仿真环境，新克隆不自包含这些资产。
